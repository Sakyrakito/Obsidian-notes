>[!info]
>Функция возвращает gcd(a, b).
>Перед вызовом нужно создать x, y и передать их как последние параметры - это решение нашего уравнения (ax + by = 1).
>
>После этого нужно умножить на коэффициенты которые нам нужны (условно x \*= n / g), где g - gcd(a, b), а изначальное a и b поделить на g

```c++
int ext_gcd(int a, int b, int& x, int& y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }

    int x1, y1;
    int g = ext_gcd(b, a % b, x1, y1);
    x = y1;
    y = (x1 - a / b * y1);

    return g;
}
```
